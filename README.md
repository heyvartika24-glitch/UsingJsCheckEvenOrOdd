# Even or Odd Number Checker

This is a simple JavaScript program that checks whether a number is even or odd using the modulus (%) operator.

## Features

- Checks multiple numbers
- Uses if...else statements
- Displays output in the browser console

## Technologies Used

- HTML5
- Css3
- JavaScript

## Project Structure

```
Even-Odd-Checker/
│── index.html
│── style.css
│── script.js
│── README.md
```

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Open the browser console (F12 → Console) to view the results.

## Sample Output

```
The number 5 is Odd.
The number 8 is Even.
The number 11 is Odd.
The number 20 is Even.
```
